# 直播源使用与反馈说明

> 这份文档回答两个问题：**普通用户**怎么用内置源或自己的订阅源；**反馈失效频道**时怎么写，处理起来更快。

## 一、直播源的两种来源

| 来源 | 说明 | 入口 |
| --- | --- | --- |
| 内置源 | 央视、卫视、地方台等常用频道，属于增值服务，完整内置源需赞助开通 | App 内开通 |
| 自定义源 | 填写自己的 m3u / txt 订阅地址 | 设置 → 自定义直播源 |

- 「设置 → 直播源 → 默认源服务」留空时，App 只加载「自定义直播源」里填写的订阅，不再使用内置源。
- 自定义源由你自己的订阅服务提供，频道内容与可用性取决于该订阅本身。
- 请勿在仓库任何地方粘贴付费源、内网 IPTV 地址或需要鉴权的链接。

## 二、客户端这一侧做了什么

| 机制 | 触发条件 | 动作 |
| --- | --- | --- |
| 自动换源 | 播放出错 | 立即切到下一个源 |
| 卡顿切源 | 缓冲中断 2 秒未恢复 | 立即切源 |
| 起播停滞检测 | 起播缓冲 4 秒无进展 | 判死并切源 |
| 坏源本地退避 | 播放失败 | 本地记下坏源，指数退避（10 分钟 → 24 小时），成功即恢复 |

也就是说：**你在真实环境里遇到的坏源，App 会当场绕开，并在之后的播放里主动避开它。**

## 三、失效频道怎么反馈（重点）

在 [Discussions 的「源失效反馈」分类](https://github.com/HTWMedia/HTV/discussions)发帖，或到 QQ 群（可加入「HTV及视频创作交流二」1049642435）反馈，**按这个格式写**：

```
频道名：CCTV-5
现象：黑屏 / 一直转圈 / 卡住不动 / 提示播放失败
所在地区 + 网络：山东 · 联通宽带
App 版本：v6.0.6
```

为什么这么要求：

- **地区很关键**——不少源是分省 IPTV 出口，同一个频道在你那里挂、在我这里是好的
- **现象决定处理方式**——黑屏多为源死了；转圈可能是并发限流；特定时段才卡可能是高峰限速
- 信息越完整，越容易定位是内置源还是自定义源的问题

## 四、自定义源的常见问题

- **填了自定义源还是看不到新频道？** 确认「默认源服务」是否已留空，并检查订阅地址本身是否可访问。
- **自定义源和内置源能同时用吗？** 可以，两者互不影响；留空默认源服务时只使用自定义源。
- **想换成自己的订阅接口？** 在「设置 → 自定义直播源」替换订阅地址即可，无需重新安装。

## 五、常见疑问

**为什么同一个频道画质时好时坏？**
不同源的码率不同，自动换源后画质会跟着变。多源互为备份是稳定优先的设计取舍。

**为什么有的地方台只有别的省有？**
频道按省级区分，港澳台及少数地区默认使用北京的源。如果你所在的省缺频道，欢迎反馈。

**内置源需要付费吗？**
App 免费；完整内置源需赞助开通。不想使用内置源时，可以只用自定义源。
